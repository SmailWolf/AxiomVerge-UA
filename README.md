# Axiom Verge — українська локалізація

Неофіційний українізатор для **Axiom Verge (2015)**. У цьому репозиторії доступний вихідний пакет патчера: він збирає файли локалізації з оригінальних файлів гри, встановленої у вас.

## Завантаження та встановлення

1. Завантажте [`AxiomVerge-UA-source-v1.zip`](AxiomVerge-UA-source-v1.zip) і розпакуйте його.
2. Переконайтеся, що у вас є оригінальна PC-версія гри з підтримуваною версією `AxiomVerge.exe`.
3. Встановіть Node.js і Python 3.
4. У розпакованій папці проєкту виконайте `npm install` і `python3 -m pip install -r requirements.txt`.
5. Запустіть `npm run patch -- "/повний/шлях/до/Axiom Verge"`.
6. Перевірте звіт збірки в папці `build`, зробіть резервну копію гри та скопіюйте зібрані файли патча до папки гри із заміною.

Патчер звіряє версію EXE і працює з локальними файлами вашої копії гри. Якщо контрольна сума не збігається, патчер зупиняється. У пакеті немає EXE, XNB чи інших файлів гри.
