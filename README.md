# Axiom Verge — українська локалізація

Неофіційний українізатор для **Axiom Verge (2015)**. У цьому репозиторії доступний вихідний пакет патчера: він збирає файли локалізації з оригінальних файлів гри, встановленої у вас.

## Завантаження та встановлення у Windows

1. Завантажте [архів вихідних файлів](AxiomVerge-UA-source-v1.zip) і розпакуйте його.
2. Переконайтеся, що встановлено оригінальну PC-версію гри з підтримуваною версією `AxiomVerge.exe`.
3. Встановіть Node.js та Python 3. Під час встановлення Python увімкніть його launcher (команду `py`).
4. Відкрийте PowerShell у розпакованій папці проєкту — тій, де лежить `package.json`.
5. Виконайте команди нижче. Замініть шлях на свою папку гри, якщо вона встановлена не у стандартному місці Steam.

```powershell
npm install
py -3 -m pip install -r requirements.txt
$env:PYTHON = "py"
npm run patch -- 'C:\Program Files (x86)\Steam\steamapps\common\Axiom Verge'
```

Патчер збере файли в папці гри: `build\Axiom Verge UA patch`. Перевірте `build-report.json`, зробіть резервну копію оригінальних файлів, а потім скопіюйте вміст папки патча до папки гри із заміною.

Патчер перевіряє контрольну суму EXE і працює з локальними файлами вашої копії гри. Якщо версія не збігається, він зупиняється. У репозиторії немає EXE, XNB чи інших файлів гри.
